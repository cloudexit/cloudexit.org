## 直接答案 {#answer}

只看“每 GB 多少钱”无法完成块存储比较。它会在基线场景把 gp3 排得更便宜，
又在性能对齐后把答案完全翻转。一张合格账单至少要计算四类成本：

\[
\begin{aligned}
\text{块存储月成本} ={}& \text{容量} + \text{IOPS} + \text{吞吐} \\
&+ \text{快照与恢复} + \text{网络路径}
\end{aligned}
\]

实际可用性能还受实例限制：

\[
\text{可用 I/O} = \min(\text{云盘上限}, \text{实例存储通道上限})
\]

花钱购买实例无法交付的 IOPS，只会增加成本，不会增加性能。

## 两种定价哲学 {#philosophies}

### AWS EBS gp3：容量与性能是显式计量项 {#gp3}

快照口径为：

- 容量：`$0.08/GB月`（`¥0.5425`）。
- 内含：`3,000 IOPS` 与 `125 MiB/s`。
- 额外 IOPS：`$0.005/IOPS月`。
- 额外吞吐：准确 `us-east-1` 快照中为 `$0.04/MiB/s月`。

因此：

\[
\begin{aligned}
C_{gp3} ={}& 0.08G + 0.005\max(I-3000,0) \\
&+ 0.04\max(T-125,0)
\end{aligned}
\]

三项都是预配计费，实际用得少不会退还闲置 IOPS 或吞吐费用。

### 阿里 ESSD：容量通常自带一条性能曲线 {#essd}

传统 PL0–PL3 把容量和性能等级绑定。AutoPL 把容量与可选预配置/突发性能拆开，
但容量仍然自带随容量增长的基准：

\[
I_{base}=\max(\min(1800 + 50G, 50000), 3000)
\]

\[
T_{base}=\max(\min(120 + 0.5G, 350), 125)
\]

200 GiB 对应 11,800 IOPS、220 MB/s；2,048 GiB 时达到 50,000 IOPS、350 MB/s 上限。
阿里官方文档同时明确，实例通道可能成为更低的 I/O 上限。

| EBS gp3 | `¥0.5425/GiB月` | 3K IOPS、125 MiB/s | 同一目录计量项 | 合同相关 | 合同相关 | 合同相关 |
| ESSD PL0 | `¥0.50/GiB月` | 随容量增长 | `¥0.7665` | `¥0.425` | `¥0.25` | `¥0.25` |

| ESSD PL2 | `¥2.00/GiB月` | 更高等级；最小 461 GiB | `¥3.066` | `¥1.70` | `¥1.00` | `¥1.00` |

这一层里，gp3 接近 PL0，约为 PL1/AutoPL 的 54%。这句话正确，但不完整。

## 等性能场景 {#matched}

| 容量与目标 | EBS gp3 | ESSD AutoPL 基准 | gp3 / AutoPL | 结论 |
| --- | ---: | ---: | ---: | --- |
| 200 GiB · 3K IOPS · 125 MiB/s | `¥108.51/月` | `¥200.00/月` | `0.54×` | gp3 基线更便宜 |
| 200 GiB · 11.8K IOPS · 220 MiB/s | `¥432.67/月` | `¥200.00/月` | `2.16×` | AutoPL 容量基线更便宜 |
| 2,048 GiB · 50K IOPS · 350 MiB/s | `¥2,765.85/月` | `¥2,048.00/月` | `1.35×` | AutoPL 在基线上限仍更便宜 |

这就是块存储的核心洞见：**一个产品单独收性能费，另一个把随容量增长的基准打包在容量里，
所以答案会翻转。** 它不证明延迟、耐久性、突发行为或实例交付能力等价。

## 价格表仍然隐藏了什么 {#hidden}

### 快照与恢复 {#snapshots}

EBS 快照按 S3 后端的已改变块计费；跨地域复制、归档取回、Fast Snapshot Restore、
限时复制和预配初始化还会增加独立计量项。ESSD 快照、备份产品和跨地域恢复也有自己的生命周期与传输费。
恢复预算必须包含恢复时间和恢复吞吐，不能只看快照 GB 月价。

### 拓扑与网络 {#topology}

单块云盘属于一个可用区。跨 AZ 数据库或应用拓扑可能复制多份云盘，并增加网络费用。
托管数据库存储还可能对容量、IOPS 和吞吐使用不同于裸块存储的管理系数。

### 预配与消耗 {#provisioned}

容量和性能都可能在使用前先付钱。至少跟踪：

- 预配与实际使用 GiB；
- 预配与 P95/P99 实际 IOPS；
- 预配与实际吞吐；
- 实例存储通道利用率；
- 快照增长与孤儿保留；
- 承诺覆盖和剩余期限价值。

## 极致性能层 {#extreme}

高端产品中，容量不再是主要计量项。AWS io2 按单卷阶梯出售预配 IOPS；
阿里 ESSD PL-X 同样拆分容量和 IOPS。官方 2,048 GiB、200 万 IOPS 示例月费 `¥152,048`，
其中 `¥150,000` 来自性能。低端盘按容量赚钱，高端盘按性能赚钱。

## 历史洞见 {#history}

AWS gp2 到 gp3 容量价只从 `$0.10` 降到 `$0.08/GB月`，下降 20%。
但 200 GiB 卷的内含基线 IOPS 从 600 升到 3,000，每基线 IOPS 价格下降 84%。
阿里 2016 SSD 与 2026 ESSD PL1 都锚定 `¥1/GB月`；容量计量项不降，可以与性能、可靠性和产品语义升级同时成立。

所以“存储容量价没有降”和“存储价格性能大幅改善”可以同时为真。参见[云价历史](/zh/ledger/price-history/)。

## 最低合格账单表 {#worksheet}

比较云盘前，每块盘至少填写：

| 字段 | 必填值 |
| --- | --- |
| 地域 / AZ | 准确部署路径 |
| 预配与实际容量 | 两个 GiB 数字 |
| IOPS | 基线、预配、P95/P99 实测 |
| 吞吐 | 基线、预配、P95/P99 实测 |
| 延迟要求 | P50/P99 与块大小 |
| 实例通道 | 最大 IOPS 与吞吐 |
| 快照与恢复 | 变化 GB、保留、RTO、复制路径 |
| 拓扑 | 云盘数、副本数、AZ 数 |
| 期限 | 按量、包月、1/3/5 年、剩余承诺 |

缺少其中任何一项时，容量价比只能作为线索，不能作为结论。

## 边界 {#boundaries}

- GB 与 GiB 按厂商原始口径保留。
- AutoPL 基准不代表挂载实例一定能交付该性能。
- 本页没有统一延迟、耐久性、突发或 SLA。
- AWS 价格按地域且不含税；阿里中国站价格含税。
- 2026-08-22 后可能已经变化，采购前必须刷新。
