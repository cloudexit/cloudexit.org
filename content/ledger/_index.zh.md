云账单不是一个价格，而是一组资源计量项、拓扑、活动费、时间承诺与商务条款叠起来的结果。
这份账本先把这套堆栈摊开，再回答钱到底花在了哪里。

> [!IMPORTANT]
> **价格快照：** 2026-08-22 · **研究完成：** 2026-08-24 ·
> **主样本地域：** AWS `us-east-1`、阿里云 `cn-hangzhou` ·
> **汇率：** 1 USD = 6.7817 CNY · **月时数：** 730。
> 以下都是带日期的公开价或情景值，不是实时报价，也不是企业合同净价。

## 一条公式看懂账单 {#formula}

\[
\begin{aligned}
\text{有效成本} ={}&
\sum(\text{用量} \times \text{单价} \times \text{拓扑} \times \text{期限}) \\
&+ \text{活动费} + \text{网络} + \text{支持} + \text{税} \\
&- \text{额度}
\end{aligned}
\]

分母同样重要：

\[
\text{有效单位成本} = \frac{\text{现金账单}}{\text{有效业务产出}}
\]

一份五折承诺若只有 60% 被有效使用，实际单位价是按量的
`0.50 / 0.60 = 83.3%`，并不是五折。折扣可以降低发票，却同时增加搁浅价值与退出风险。

## 六个经得住细节的结论 {#findings}

| 洞见 | 已复核数字 | 能说明什么 | **不能**说明什么 |
| --- | ---: | --- | --- |
| 同族算力按核近似线性 | AWS `c7i/m7i/r7i` 同核系数约 `0.885 / 1 / 1.313`；阿里 `c9i/g9i/r9i` 约 `0.779 / 1 / 1.330` | 大规格不会自动获得核单价折扣 | 相同 vCPU 标签等于相同业务性能 |
| 弹性有明确溢价 | 阿里 `g9i.large` 按量跑满 730 小时是包月的 `1.521×`；只看时间的交点为 `65.8%` 利用率 | 按量与包月出售不同的风险 | 超过该利用率后包月一定更优 |
| 块存储排序会随性能翻转 | 200 GiB 基线：gp3 `¥108.51`、AutoPL `¥200`；对齐 11.8K IOPS / 220 MiB/s：gp3 `¥432.67`、AutoPL `¥200` | 只比容量会把结论算反 | 两种盘在任何实例、延迟下都性能等价 |
| 对象容量价已经接近 | S3 Standard `¥0.156/GB月`；OSS Standard LRS `¥0.120` | 容量已经不是整张账单 | 请求、取回、最短时长、小对象和出网等价 |
| 最小可靠拓扑决定自建门槛 | 对比 OSS 一年包：8 节点单站 `199 TB`；双站 `536 TB`；三站稳定交点 `1,223 TB` | 对象存储拐点首先是拓扑问题 | 单站存储池等价于 S3 服务等级 |
| 成熟账单比算力降得慢 | AWS 容量篮子 2008→2026：`-63.0%`；阿里包月篮子 2016→2026：`-4.8%` | 不降的存储与流量会稀释算力红利 | 两个篮子在性能或 SLA 上等价 |

## 三张账单表面 {#surfaces}

### 计算：给真正有用的核定价 {#compute}

同一实例族中，规格大小主要减少运维对象数量，不会明显降低每核价格。
架构、内存配比、地域、代际和购买期限才会实质改变单位价。
[计算账本](/zh/ledger/compute/)给出当前参考规格、地域系数、承诺交点和离散的自建规模曲线。

### 块存储：容量与性能必须一起定价 {#block}

gp3 把容量、IOPS 与吞吐拆成三个计量项；ESSD AutoPL 的容量自带随容量上升的基准性能，
还可以叠加预配置和突发计费。[块存储账本](/zh/ledger/block-storage/)用同样容量、IOPS 与吞吐比较三个场景，
同时保留实例存储通道上限——买到实例用不完的 IOPS 没有价值。

### 对象存储：别只给 TB 定价 {#object}

对象账单是存储类别 + 最小计费对象 + 最短存储期 + 请求 + 取回 + 复制 + 传输。
[对象存储账本](/zh/ledger/object-storage/)再加上自建的最小可靠拓扑，
避免把 `100 TB`、`500 TB` 和 `1 PB` 当成同一个工程问题。

## 长期洞见 {#history}

云价在早期竞争期快速下降，此后许多核心边际价进入平台。
AWS S3 Standard 自 2016 年保持 `$0.023/GB月`，AWS 公网出流自 2014 年保持 `$0.09/GB`；
报告的 2016–2026 锚点中，阿里 ESSD PL1 容量仍为 `¥1/GiB月`，ECS 出网仍为 `¥0.8/GB`。
算力继续进步，但用户通常必须迁代、换架构或改变购买方式才能真正拿到红利。

完整指数和账单篮子见[云价历史](/zh/ledger/price-history/)。

## 决策规则 {#decision}

1. 先建立 90–180 天工作负载指纹：逐时计算、容量、IOPS、吞吐、对象大小、请求、取回与全部网络路径。
2. 把稳定低谷、可预测峰值、可中断任务和有状态数据分开。
3. 统一拓扑与有效性能，再比较价格。
4. 计算承诺利用率和搁浅价值，而不是只看宣传折扣。
5. 把公开价、真实账单和自建采购作为三层分别比较。
6. 成本拐点只是进入工程评估的门槛，不是自动迁移指令。
