## 记录结构 {#shape}

| 字段 | 作用 |
| --- | --- |
| 准确说法 | 原话或忠实且有边界的转述，带日期与链接 |
| 说法类型 | 价格、可用性、可移植性、安全、性能或市场表述 |
| 适用范围 | 产品、地域、套餐、工作负载与时间窗口 |
| 验证方式 | 能够证实或证伪的观察与计算 |
| 证据 | 一手数据优先，其次是可复现或独立来源 |
| 状态 | 支持、混合、矛盾、未决、过期或撤回 |
| 回应 | 厂商纠错、补充背景或异议，并完整链接 |

这一节必须保持对称：一条厂商说法如果经受住严格验证，也应获得与失败说法同等的展示。
目标是问责，不是永久敌对姿态。
