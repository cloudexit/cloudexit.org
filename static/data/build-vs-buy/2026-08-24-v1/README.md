# Build versus buy · 2026-08-24-v1

Discrete scale curves and material-cost breakpoints for self-hosted compute,
PostgreSQL RDS-like services, object storage, and internet egress.

- Cloud price input: 2026-08-22 snapshot
- Model date: 2026-08-24
- Baseline: 5-year straight-line hardware life, 70% compute fill, 8% economic annuity cross-check
- Labor and migration project cost: excluded from baseline
- Status: released scenario snapshot; not a procurement quote or migration directive

Both first and durable crossings are published because server, rack, storage-pool,
and port purchases create a sawtooth cost curve. See `report.md` and
`tables/assumptions.json` before using a breakpoint.
