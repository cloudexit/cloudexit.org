# Methodology

The effective bill is decomposed into resource, product, spatial, topology,
time, and commercial/financial layers. Public list price, public discounted
price, and enterprise effective price are kept separate.

Primary comparison rules:

1. Match region, architecture, generation, memory ratio, topology, and billing term.
2. Compare block storage by capacity, IOPS, and throughput—not capacity alone.
3. Compare object storage by storage class, object size, minimum duration, requests, retrieval, and transfer.
4. Treat commitment discounts as utilization-risk transfers.
5. Label every number with the 2026-08-22 snapshot date.

See `report.md`, `tables/analysis_manifest.json`, and `tables/source_ledger.csv`.
